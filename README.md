## Analytics

쿠키 없이 사람·에이전트 유입과 유입 경로를 분리해 기록한다. URL 쿼리 전체,
리퍼러 경로, IP 주소, 전체 User-Agent는 저장하지 않는다.

배포와 조회 방법은 [`analytics-worker/README.md`](analytics-worker/README.md)를 참고한다.
